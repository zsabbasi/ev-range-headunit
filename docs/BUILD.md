# Build and test

Windows PowerShell. No Gradle: only the Android SDK command-line tools and a JDK.

## Prerequisites

- JDK 8 or newer (`javac`, `keytool`); tested with JDK 17.
- Android SDK with `build-tools` (any recent version) and `platforms;android-28`. Set `ANDROID_HOME`, or install to `%LOCALAPPDATA%\Android\Sdk`.
- Python 3 (`py` or `python`) for the packaging helper, the icon generator and the tools.
- For the hook: internet access once, to fetch the public AOSP platform test key.

## Tests (no device)

```
.\scripts\test.ps1
```
Runs: the range engine on `samples/ev_demo_sanitized.csv` (about 2.63 km at the calibrated 31.0 km/h per 3000 rpm, 15.8 kWh/100 km, save/load round trip), the power-bar scale tests, the speed tests (rpm conversion, GPS agreement rule), the 17 safety-brake tests of the feed against a fake car library, and the calibration tool's self-test.

## The app

```
.\app\build.ps1
```
Output: `build\app\evrange.apk`. It is signed with a **debug** keystore created on first run (`build\debug.keystore`, ignored by git). For anything you distribute, create your own private release keystore and pass `-Keystore` / `-StorePass`; keep it out of the repository. Updates only install over each other if signed with the same key, so keep using the same keystore for every build you install on a unit.

The launcher icon is generated by `app\make_icon.py` (no image libraries needed).

## The data feed

```
.\hook\build.ps1
```
Output: `build\hook\evhook.apk`. The script downloads `platform.pk8` / `platform.x509.pem` from the Android source tree (public files), **checks the certificate fingerprint** (`27196e386b875e76adf700e7ea84e4c6eee33dfa`), and signs with them. The package declares `android:sharedUserId="android.uid.system"`, so it installs only on a unit whose firmware uses the same key. Keys are written to `build\aosp_keys` and ignored by git.

## Reproducibility

The code inside `evhook.apk` built from this repository is byte-identical to the build that ran on the test unit (SHA-256 of `classes.dex` `5c71769627c56106a890dc3586e71a1abd288014c0cfa5b6be52007faf40741d`). The whole-file hash differs because signing is not byte-reproducible.

## Layout of what the build produces

`build\` is ignored by git. Nothing in it should ever be committed.
